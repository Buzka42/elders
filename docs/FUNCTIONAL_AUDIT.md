Audit date: 2026-11-10 02:35 CET. Read-only: no code was edited. Plan under test: `docs/BLOODSPORTS_V2_PLAN.md` (§1 decisions, §3.4 modules, §4 phase table, §7 acceptance).
Repos read: `~/Projects/bloodsports`, `~/Projects/elders` (MetaKit, Elders), `~/Projects/wom-backend`, plus `~/Projects/world-of-meta/site` for the site side.

## 0. Method and caveats

- Evidence is file:line from the working trees as they were at audit time. Both addon repos are **dirty** (UI/Shell WIP in elders, ~10 UI files + untracked `tests/test_hostile_ring.lua`, `test_judge{3,4,5}_ui.lua` in bloodsports). `Ring.lua` was being edited by another lane while I read it (line numbers moved by ~18 between reads; see G3). Cite lines as "about".
- Suites run by me: bloodsports `tests/run.sh` green (26 files, incl. the new hostile-ring file, 28/28 after the concurrent edit); elders `tests/run.sh` exit 0 (27 files); wom-backend `npm test` 204/204 pass. Green tests prove the code agrees with itself, not that the plan is met; every claim below is from reading code.
- Nothing was run in the game client. "DONE" means implemented and covered by a Lua stub test or a code path I traced, not live-verified (P6 live ring test is its own row).

## 2. Ranked gap list (impact × effort)

|---|---|---|---|---|---|
| G1 | **Series state never reaches a third-party referee.** `SERIES_*` fire only on fighters' clients; Ring on a non-fighting host never sets `s.series`, so series markets cannot be created or settled by the usual referee. Works only when the host is one of the two fighters (who also cannot bet on own markets). | H | M | `Series.lua:139,173,117`; `Duel.lua:228-244`; `Ring.lua:~1515-1545,~1397`; wire list `Ring.lua:2447-2465` has no series message | Add a fighter→host whisper (`R2T`: series id, bo, a, b, round winners, done) sent from `SERIES_START/ROUND/DONE`; host accepts only from the two named fighters and requires both to agree (or referee's `CHAT_MSG_SYSTEM` round count as the tie-break).
