The Elders watch your road.

Elders is a lightweight leveling companion for WoW Forever. It sits quietly in the background and records how you level — then shows it back to you in one clean panel.

What it tracks (per 1–10 … 51–60 bracket):

  • Pace: XP per hour, XP per kill, quest share, time per level, rested value
  • Downtime: combat, travel, idle, eating, deaths, corpse runs
  • Combat, economy, dungeons, talents — snapshots as you play

The ritual: every 10 levels the Elders ask three things — rate your last bracket, judge class insights from other players, optionally leave one of your own (280 chars). Your votes feed the World of Meta tierlists and the R1–R14 elder ranks.

Your data, your control:

  • Random character IDs — no RealID, no chat scraping, no memory reading
  • Syncs through the tiny Meta Uploader app (or a copy-paste export string)
  • Everything visible on your World of Meta account page

Commands: /elders (panel) · /elders ritual · /elders export · /elders sync
Requires: Meta Uploader for automatic sync.
Supports: WoW Forever. Bloodsports (duels, fight clubs, goblin-ring betting) is its sister addon — same account, same uploader.

Syncing: the Meta Uploader (open source). The addon itself never touches the network. The Meta Uploader is a tiny desktop app that reads the SavedVariables files the game already wrote to disk, uploads only new rows to World of Meta, and writes ranks, insights and acknowledgements back into your AddOns folder as the WorldOfMeta_Data addon. It never reads game memory, never sends keystrokes, never touches chat. Python 3.10+, standard library only.

  • Windows: MetaUploaderSetup-1.0.0.exe
  • Linux: meta-uploader-1.0.0-linux-x86_64.tar.gz
  • Source code (verify it yourself): github.com/Buzka42/elders/tree/v1.0.0/uploader — includes the full README (every file, every network call documented), unit tests, SHA256 checksums and the build scripts, so you can build the binaries yourself instead of trusting ours.
